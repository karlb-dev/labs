# OLMo lineage reproduction and isolation contract

Status: binding for this side study. All native evidence is development or
methods tier.

1. The immutable Phase 4 import boundary is commit `3b041735...`. Later
   documentation-only ancestry is recorded separately and does not expand the
   imported scientific boundary.
2. Outputs may be written only below the OLMo Drive root and the repository
   namespace `interpretability/jspace_olmo_lineage/`.
3. The append-only registry accepts only `ol-` evidence IDs. It never writes
   a Phase 3, Phase 4, or Gemma registry.
4. Imported artifacts are verified by source-registry hash, live event,
   reachable source commit, path, bytes, and SHA-256. Imported parquets are
   read-only inputs.
5. A model result requires a clean code commit, immutable input manifest,
   pinned model/tokenizer revision, same-process CUDA gate, local-NVMe model
   snapshot, resumable state, raw rows, and hashes for every output.
6. CPU fallback for model work and DriveFS model loading are forbidden.
7. Bank W capability scoring is baseline-only, uses the full frozen eight
   candidate sequences, and contains no intervention column.
8. No untouched Phase 4 confirmatory or replication intervention outcome may
   be opened. Side-study Bank-W interventions use only development families.
9. Existing live artifacts are never overwritten. Corrections and
   supersessions are append-only events with new evidence IDs.
10. Every headline table reconstructs from immutable rows and every figure
    regenerates from registered tables.
11. The Instruct checkpoint is always a sibling endpoint, never a fourth
    temporal point on the Think path.
12. Pushes on this branch first pull/rebase the remote OLMo branch. The final
    bundle is merged into mainline with ancestry preserved.
13. Live recovery/report mirrors are mutable operational documents, never
    immutable registry outputs. Their recovery index records source commit and
    content hashes; versioned scientific tables and manifests remain immutable.
