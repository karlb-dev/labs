# Phase 4 independent review — template

**NARRATIVE-BLIND PROTOCOL — A REVIEW THAT MERELY SAYS "LOOKS GOOD" DOES
NOT PASS**

The reviewer is a fresh session or human given only: frozen producer and
analysis code; configs and thresholds; exact registered result tables and
outputs; the event registry and its supersession graph; tests; bundle
manifests and saved validations; durability and inventory outputs; and this
checklist. The reviewer must not be given the aspirational paper narrative,
plan files, addenda, or in-progress notes before writing its verdicts, and
must state so.

## Required checks (each: PASS / PASS WITH EXPLICIT LIMITATION / FAIL, with
reconstructed numbers)

1. Q-L4 is the unique output of the frozen branch table given the
   registered structural/functional/margin/influence inputs.
2. The structural pass and sparse/causal failures use the registered
   metrics and thresholds (reconstruct: task q50/q05, ID Jaccard,
   normalized projector overlap, bridge-rescue difference).
3. Selection-margin strata do not rescue the canonical instrument
   (reconstruct the retained-position and strata counts).
4. Prompt-323 influence is negligible under the frozen materiality rules
   and is correctly scoped to the current runtime.
5. P4-P1, P4-P2, and P4-P3 dispositions follow mechanically.
6. No confirmatory or replication intervention outcome exists anywhere in
   the registry or run roots.
7. The Study-2 imports preserve source tiers and forbidden meanings.
8. Gemma V2 relicensing does not erase the historical blocker event.
9. OLMo wedge effects are missing, not zero.
10. H6 failure is not restated as invalidation of paired ablation evidence.
11. The Bank-W pair result is a power/design closure, not an
    externalization null.
12. The fresh durability proof contains only the known permanent deficit.
13. Registered figures/tables in the freeze packet match their registered
    hashes.
14. The proposed terminal prose does not exceed any claim ledger.
