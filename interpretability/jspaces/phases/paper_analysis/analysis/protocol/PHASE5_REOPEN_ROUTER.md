# PHASE5_REOPEN_ROUTER.md — go/no-go rules for any Phase 5 branch (P0, frozen)

The offline phase ends with a decision (`reports/PHASE5_REOPEN_DECISION.md`),
never an automatically generated plan. A no-go outcome is explicitly
acceptable. Candidate list source of record:
`interpretability/jspaces/phases/phase4/paper/PHASE5_HORIZON.md`.

## General go criteria — ALL must hold

1. one primary scientific question is named;
2. the result would change a central paper sentence;
3. the estimator and population are prospectively specified;
4. a positive, negative, gated, or null result is useful;
5. the design is not a post-hoc rescue of Phase 4;
6. power or precision is adequate;
7. model/lens validity gates are explicit;
8. the GPU budget and stop rule are bounded;
9. no frozen holdout or registry boundary is violated;
10. the paper analysis identifies the missing result as worth delaying
    publication.

## Candidate-specific gates

**5A OLMo Bank-W pair completion** — go only if: ≥18 genuinely common
capable families under a new outcome-blind authoring protocol; family
authoring never based on intervention outcomes; capability and partition
frozen before intervention; the exact two-model max-T ruler passes; H6
limitations reflected in wording; the route decision says the result
would materially change the externalization conclusion. (Leading
near-term candidate, not an automatic continuation.)

**5B Qwen consensus/cross-fit instrument** — go only if: the estimand is
defined entirely from generic fit data or consumed development data;
simulations show it distinguishes stable conclusions from lens
sensitivity; no A2000; the result changes whether a Qwen causal primary
is interpretable in future work; an independent methods review passes.

**5C capability-compatible OLMo stage assay** — go only if: conceptually
equivalent (not merely easier); capability demonstrated prospectively
across Base/SFT/DPO/3.0-Think; enough independent families; no current
wedge outcome reused as a target-selection signal; stage predictions and
analysis frozen before intervention.

**5D actual-dose transport validation** — go only if: exact site-level
dose logging added prospectively; the causal assay reruns on development
items or a new partition only; the ε mapping is frozen before tangent
outcomes; the result directly determines whether crossed-lens/patching
designs are interpretable.

**5E Gemma mechanism localization** — go only if: existing Study-1
vectors identify one or two discriminating candidate accounts;
attention/MLP/norm/routing tests have prewritten directional predictions;
no broad architecture safari; the result belongs in the methods paper;
a half- or one-block cap suffices.

## The acceptable no-go sentence

> No Phase 5 experiment has enough expected information gain to delay
> paper drafting. Publish the frozen empirical and methods results,
> release the data package, and leave the candidate branches as future
> work.
