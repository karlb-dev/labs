## G2.1 design and execution

The full grid contained two exact checkpoints, three layers per checkpoint,
four prompts, three batch sizes (1, 4, and 8), and three independently seeded
draws from each of three delivered direction families. This yielded 216 full
exact-backend pairs. A frozen diagnostic screen contributed 16 nested
attention/MLP pair summaries without changing the full-suffix estimand.

The final artifact contains 232 pair summaries and 1,008 rows: 936 full-suffix
rows and 72 nested-operation rows. All values are finite. Every full primal
matches, all rows pass deterministic replay, all 232 pair reconstructions pass,
and every dtype-quantum reconstruction passes. A fresh-process replay also
passes. No finite difference is treated as an exact JVP.

One post-data audit correction concerned only the precision used to reconstruct
stored cosine reductions. The stored value used a float32 Torch reduction,
whereas the independent audit reconstructed float64 dot products and norms.
The largest absolute residual was `9.226683939211888e-06`, below the
dimension-derived bound `1.52587890625e-05`; no scientific row, threshold
formula, or route was changed.

## Frozen ceiling and nuisance routes

The registered ceiling is

```text
max(
  3 * q99(exact-backend tangent relative disagreement),
  q99(relative equivalent of ten target-dtype quanta)
)
```

Across the 936 full rows, the pooled disagreement q99 is
`0.026234563004519824`; three times that value is
`0.07870368901355948`. The ten-quantum q99 is
`0.06532100783179973`, so the disagreement term governs. A 5,000-draw prompt
bootstrap gives a 90% interval of `[0.07489779624371865,
0.10392247147209241]` around the registered point rule.

The batch-specific disagreement q99 values are `0.029989831154375937`,
`0.0349764520459505`, and `0.025834424240268494` for batches 1, 4, and 8.
The frozen batch-nuisance condition is not active. The normalized per-model
floor ratio is `1.250081245916701`, below the frozen factor-of-two router, so
the architecture-dependent route is not active and the pooled ceiling applies
to both checkpoints. There are no nonfinite exact backends, no reproducible
batch-1 path-ambiguity groups, and no target-field join. The selected route is
therefore `benign_scheduling_floor`.

The registered log-scale figure clips 176 exact zeros only to a display floor
of `9.991148762302825e-06`; the underlying values and all scientific summaries
remain unchanged.
