# AI Data Apps

This area explores applications that combine operational data, retrieval, local
models, and controlled actions. It is intentionally app-shaped: each lab should
leave behind a small runnable system as well as teaching notes and benchmark
evidence.

## Labs

| Lab | Status | Question |
| --- | --- | --- |
| [rag](rag/) | initial scaffold | How should retrieval, generation, and actions share a SQL Server data boundary? |
| [modelprint](modelprint/) | experiment in progress | Can generated text be attributed to one of four pinned local models, and when should the system abstain? |
| [logwarden](logwarden/) | foundation in progress | What value does a local-model incident agent add beyond strong SQL rules, and at what reliability and systems cost? |
