# Lab 03 Course Guide — LogWarden

## Learning objectives

By completing this lab, you will be able to:

1. capture SQL Server operational evidence with transactional, resumable source cursors;
2. separate a frozen replay benchmark from a live queue-and-throughput benchmark;
3. implement a durable lease-based agent state machine without holding database transactions across inference;
4. compare deterministic rules, retrieval-only behavior, and local-model agent arms on paired incident episodes;
5. evaluate structured tool use, grounding, abstention, runtime failures, and safety as distinct contracts;
6. reconstruct claim-bearing reports from retained rows and verified artifacts.

## Critical path

Complete LW-0 through LW-10 at Tier 1 before starting live systems, optional
SQL features, or a UI. The command-line and reporting views are authoritative.
Every implementation deviation is entered before the affected evidence in
`EXPERIMENT_LOG.md`, together with its impact on the claim ceiling.
